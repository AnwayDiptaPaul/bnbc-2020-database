# Section 3.5.1.1: In order to achieve noise control effectively, measures should be taken in the

3.5.1.1 In order to achieve noise control effectively, measures should be taken in the
following order:
(a) Suppression of noise generation at its source
(b) Layout planning
(c) Insulation design
(d) Absorption design
