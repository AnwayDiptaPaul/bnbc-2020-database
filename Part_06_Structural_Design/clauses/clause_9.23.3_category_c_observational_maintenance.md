# Section 9.23.3: Category C : Observational Maintenance

9.23.3 Category C : Observational Maintenance
Maintenance in which visual inspection is necessary without any remedial
action regardless of the deterioration level. Category C structures are those

for use as long as they are usable;

for which ensuring safety from threats posed to third parties is the only
requirement.
