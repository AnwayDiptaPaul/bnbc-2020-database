# Section 7.11.7.1: Building Layout

7.11.7.1 Building Layout
(a) The building should not be excessively long relative to its width; ideally,
the length-to-width ratio should not exceed 4.
(b) The walls should be continuous up the building height.
(c) Openings (doors and windows) should be placed in the same position up
the building height.
