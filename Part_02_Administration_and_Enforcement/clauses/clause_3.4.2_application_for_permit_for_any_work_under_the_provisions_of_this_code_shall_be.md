# Section 3.4.2: Application for permit for any work under the provisions of this Code shall be

3.4.2  Application for permit for any work under the provisions of this Code shall be
accompanied by necessary documents, drawings, certificates, clearances and other
relevant information as required by the Building Official  for that particular
city/town/municipality/jurisdiction area etc.
